Autonomie, Sécurité et Scénarios d'Urgence

Garantir l'accès en toutes circonstances + respect de l'intimité

⚡ Coupure électrique

Solution : Onduleur (UPS) 50-100€ pour routeur WiFi + Nuki Bridge
Autonomie : 2-4h minimum
Nuki : Fonctionne sur piles (6-12 mois)
Backup : Clé physique toujours fonctionnelle

🔋 Piles Nuki déchargées

Alerte : Notification sur tablette à 20% batterie
Changement : Aidant remplace piles (5 min)
Secours : Pile 9V externe pour déverrouillage d'urgence
Clé physique : Toujours utilisable

🚨 Urgence médicale

Code soignant : Code PIN temporaire pour accès urgence
Logs : Entrées horodatées et consultables
Bouton d'urgence : Icône "Appel aide" sur TD Snap → SMS aidants
Buzzer lumineux : Signal local + alerte distante

🔒 Respect de l'intimité

Caméra : Désactivable par Pierre à tout moment
Flux chiffré : TLS 1.2, pas de stockage cloud forcé
Contrôle total : Pierre décide qui entre et quand
Journalisation : Pierre consulte logs d'accès

Scénarios d'utilisation typiques

Scénario 1 : Infirmière arrive pour soins
1. Infirmière sonne → Pierre voit image sur tablette
2. Pierre reconnaît l'infirmière → Sélectionne "Ouvrir porte"
3. Nuki déverrouille 3 secondes → Infirmière entre
4. Porte se reverrouille automatiquement
Scénario 2 : Visiteur inconnu sonne
1. Personne sonne → Pierre voit image, ne reconnaît pas
2. Pierre active audio bidirectionnel : "Qui êtes-vous ?"
3. Visiteur répond : "Livraison colis"
4. Pierre décide : A) Ouvrir B) Demander de laisser colis C) Refuser
Scénario 3 : Urgence - Pierre ne répond pas
1. Aidant arrive, sonne, Pierre ne répond pas (malaise)
2. Aidant utilise code PIN temporaire sur Nuki Keypad (option ~79€)
3. Porte s'ouvre → Aidant entre → Assistance médicale
4. Log enregistré avec heure d'accès
Matériel sécurité additionnel :

• Nuki Keypad (clavier codes) : 79€ (optionnel)
• Bouton d'urgence sans fil : 25-40€
• Buzzer lumineux : 15-30€
Total sécurité : 169-249€ (selon options)

Gestion lumières, rideaux, volets, chauffage via la même interface TD Snap/Grid 3

Pourquoi ajouter la domotique ?

  • Autonomie étendue : Pierre contrôle son environnement complet sans aide

  • Même interface : Tout depuis TD Snap/Grid 3, pas de nouveau système à apprendre
