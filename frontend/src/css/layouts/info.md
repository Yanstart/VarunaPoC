# layouts

## But
Definir les styles CSS Grid pour les dispositions multi-viewers (comparaison de lames cote a cote).

## Pourquoi
Isoler les regles de mise en page complexes (grilles 1, 2, 4+ panneaux) du reste des styles pour faciliter l'ajout de nouveaux layouts.

## Structure
- `compare-layout.css` — Grille CSS responsive pour le mode comparaison : conteneur principal, panneaux redimensionnables, barre d'outils, indicateurs de synchronisation.
