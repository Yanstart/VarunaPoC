# Config_Integration_Infra

## But
Configuration du plugin Telemis (PACS) pour l'integration du viewer Varuna dans l'environnement hospitalier Anapath.

## Pourquoi
Le CHU utilise Telemis comme PACS. Ce dossier contient la config specifique pour enregistrer Varuna comme plugin viewer dans Telemis.

## Structure
```
Config_Integration_Infra/
  anapath_viewer.plugin.varuna.phase2.cfg   # Config plugin Phase 2 (format Anapath, 7.2 KB)
  TMRHE_Plugins_Installation (3).pdf        # Guide installation plugins Telemis (PDF institutionnel)
```

## Notes
- Format `.cfg` specifique a Telemis/Anapath (pas standard)
- Guide PDF = documentation fournisseur, a conserver pour reference
