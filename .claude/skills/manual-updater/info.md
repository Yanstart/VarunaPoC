# .claude/skills/manual-updater

## But
Mettre a jour le manuel utilisateur dans `/docs/Manuel/` quand une feature est validee.

## Pourquoi
Maintient le manuel utilisateur synchronise avec les fonctionnalites reelles du viewer.

## Comment
Invoque via `/manual-updater`. Cree ou met a jour la doc avec un langage accessible aux utilisateurs finaux (pathologistes).
