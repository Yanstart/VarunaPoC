# MLOps

## But
Definir l'architecture MLOps de VarunaPoC pour l'apprentissage continu en pathologie digitale avec feedback des pathologistes.

## Pourquoi
Ces documents constituent le plan de reference pour integrer le systeme de tags, le routage vers des modeles specialises et le pipeline de feedback dans la plateforme existante.

## Structure
- `MLOPS_ARCHITECTURE.md` - Architecture de reference complete : routage par tags, infrastructure MLOps, pipeline feedback, structures de donnees.
- `MLOPS_INTEGRATION_GUIDE.md` - Guide d'integration progressive par phases (3.1 a 3.4) pour les developpeurs et DevOps.
- `MLOPS_QUICK_START.md` - Guide de demarrage rapide (10 min) pour les developpeurs commencant l'integration MLOps.
- `MLOPS_FILES_SUMMARY.md` - Index de tous les fichiers crees pour l'architecture MLOps.
