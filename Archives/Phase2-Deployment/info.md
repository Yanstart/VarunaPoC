# Phase2-Deployment

## But
Documenter la preparation et le plan de deploiement de VarunaPoC en Phase 2 sur le reseau du CHU UCL Namur.

## Pourquoi
Ces documents detaillent l'infrastructure Docker prete au deploiement (15 fichiers) et le plan reseau Phase 2.1/2.2, necessaires pour reproduire ou auditer le deploiement sur site.

## Structure
- `DEPLOYMENT_READY.md` - Checklist de tous les fichiers crees pour le deploiement Phase 1 Docker (Dockerfiles, scripts, documentation).
- `PHASE2_DEPLOYMENT_SUMMARY.md` - Resume du deploiement Phase 2 : architecture reseau, Phase 2.1 (slides locales) et Phase 2.2 (stockage CHU).
